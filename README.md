# The Moon Hatches

A phoenix egg hatches on the surface of the moon, its shell cracking open
in the stillness of the lunar dark. Embers and shell fragments rise slowly
into the black sky, caught between gravity and flight, in a painterly
digital artwork full of glow, ash, and quiet wonder.

Running `main.ts` copies `entry.png` into the output directory given by
the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).

This piece was created for the make.fun ai-excited-01 competition.
